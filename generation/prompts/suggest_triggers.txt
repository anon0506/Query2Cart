Triggers are conversation topics or events that cause the simulated user to reveal hidden constraints or preferences. There are two kinds:

1. RESPONSIVE TRIGGERS — topics the recommendation agent might ask about.
   When the agent asks about this topic, the user reveals related constraints.
   Example: "agent_asks_budget" unlocks price constraints.

2. VIOLATION TRIGGERS — events where the agent recommends something that violates a constraint.
   When the user sees a violating recommendation, they react by revealing the constraint.
   Example: "shown_expensive_product" fires when a recommended product exceeds the user's budget.
